Gemeinsam Karten sammeln

Für Lehrkräfte: Oben auf „Neues Board starten“ klicken. Der Raumcode und QR-Code erscheinen danach automatisch. Das Feld darunter ist nur für Teilnehmende, die bereits einen Code erhalten haben.

Für Lehrkräfte: Oben auf „Board starten“ klicken. Dann erhältst du einen Raumcode und einen QR-Code für deine Kolleginnen und Kollegen.

Das Feld „Raumcode“ unten ist nur für Teilnehmende, die einen bereits vorhandenen Code bekommen haben.

Der Lehrkraft-Link enthält einen geheimen Verwaltungsschlüssel. Diesen nicht an Teilnehmende weitergeben.
